# University AI Implementation — Portfolio Artifacts

Practical artifacts demonstrating AI implementation in higher education: workflow mapping, use-case prioritization, and staff capability building.

## What's here

| File | Purpose |
|---|---|
| [ai-opportunity-map.md](ai-opportunity-map.md) | Scored prioritization of a university process (student enrollment) for AI-assisted improvement — value / simplicity / risk / sustainability / readiness. |
| [workshop-ai-draft-not-grade.md](workshop-ai-draft-not-grade.md) | Hands-on workshop teaching non-technical staff to use AI safely ("draft, don't grade"), with a prompt library and one-page handout. |

## The approach

**Design → document → teach → transfer.** Find a repetitive workflow, build a low-risk improvement, document it, train the team, and hand ownership back. The goal is institutional capability, not dependence on a specialist.
